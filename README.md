# 极片涂层细裂纹的端侧检测

用公开电极涂层图像训练裂纹分割模型，评估它在 x86 CPU 上做 INT8 推理时的检出能力与处理速度，并在可调节拍的工位仿真中观察积压、丢帧和超时。第一版的实测平台是笔记本 CPU。成像与工位输入来自离线数据和模拟触发。

## 第一次运行

在项目目录执行以下命令。准备脚本会从 CoatingVision 作者仓库的固定版本取回 8 对示例并校验文件，再生成独立的原图、二值标注和叠加图。

```powershell
python -m pip install numpy pillow
python prepare_samples.py
```

打开 `data/coatingvision-demo/overlays/sample1.png`。左半边是原图，右半边的红色表示参考标注。试着在左半边指出同一条细裂纹，并找到它最难辨认的一段。用 `data/coatingvision-demo/manifest.csv` 核对尺寸与像素数。这里的 8 张图用于检查读图与标注解析。

## 项目各阶段

1. 核对原图、标注通道与来源，用来源分组划分训练、验证、量化校准和测试数据。
2. 训练输出单通道裂纹分数图的分割模型，保存验证集上选出的权重，导出 FP32 ONNX。
3. 用校准集得到 INT8 模型。在同一 CPU 和测试集上比较两份模型的裂纹召回、无裂纹图误报、Dice 与端到端耗时。
4. 让仿真工位按固定间隔触发图像，把逐帧实测耗时送入有限容量的队列，记录每帧按时完成、超时或丢弃的原因。
5. C++ 学习从一帧图像的尺寸开始，逐步实现能与 Python 基准逐帧核对的推理程序。

原始图像和运行缓存保存在本地。研究数据来自 Sampath 等人的 CoatingVision，实验涂层样本可用于验证方法。厂内光源、相机、生产卷及剔除机构的表现需要额外测量。[数据与许可](https://doi.org/10.6084/m9.figshare.29260121.v1) · [作者样本仓库](https://github.com/vigsam-coder/CoatingVision)
